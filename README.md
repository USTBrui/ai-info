# AI 资讯每日看板

> 一个**完全免费**的 AI 资讯看板：每天自动抓取你关心的 AI 新闻、论坛热帖、厂商更新和优惠活动，
> 双击网页就能一眼看完，不用装服务器、不用花一分钱。
>
> Author: wr

## 它是干什么的

每天（或你双击一下），程序会按顺序做完这些事：

1. 按 `配置/数据源清单.json` 的清单，去各个网站抓最新内容（RSS / GitHub Atom / 网页比对三种方式）；
2. 自动去重、把同一件事的多个报道合并成一条，并标注「N 个源报道」；
3. 按你关注的关键词打分排序，把**优惠活动、论坛热议、厂商动态、更新日志**分门别类；
4. 生成一份纯静态网页，**双击就能看**（`file://` 直接打开，不需要服务器）。

> 配了 DeepSeek API Key 时，会用 AI 生成一句话摘要和每日简报（约每月 1~3 元）；
> 没配也完全能跑，自动降级成「规则模式」。

## 看板长什么样

| 区域 | 内容 |
| --- | --- |
| 今日简报 | 一句话概括今天值得知道的事，右上角标明「AI 智能摘要」还是「规则模式」 |
| 优惠活动 | 自动识别「免费、限免、折扣、赠送额度、降价」，橙色卡片横排展示 |
| 今日要闻 | 全部资讯按重要度排序，多源报道自动合并 |
| 论坛热议 | 大佬说、LinuxDo 等热帖，按回复数排序 |
| 厂商动态 | 点厂商标签（DeepSeek、智谱、Kimi…）看它今天有什么动静 |
| 更新日志 | 各厂商 changelog，按天排列，今天的高亮 |
| 右侧栏 | 数据源健康状态、关注词命中统计、历史归档、导出 Markdown |

常用操作：点标题看原文并自动标记已读；点 ☆ 收藏；按 `/` 搜索、`S` 只看收藏、`Esc` 清空；
右上角 ☾/☀ 切换深色浅色。收藏和已读存在浏览器本地。

## 三分钟跑起来

1. 安装 **Python 3.9+**（[官网下载](https://www.python.org/downloads/)，安装时务必勾选 **Add Python to PATH**）。
2. （可选）装两个增强库，装不上也不影响使用：

   ```bash
   pip install -r requirements.txt
   ```

3. **双击 `一键刷新.bat`** —— 抓完自动打开看板。以后每天想看，再双击它就行。

想手动跑的话，在项目根目录执行：

```bash
python src/main.py                # 正常跑一次
python src/main.py --no-ai        # 不花钱、不用 AI，纯规则排序
python src/main.py --only=qbitai,solidot   # 只抓指定的源（用配置里的 id）
python src/main.py --dry-run      # 只抓不写文件，用来试配置对不对
python src/main.py -v             # 把每一条标题都打印出来
```

## 加 / 改信息源

不用改代码，编辑 `配置/数据源清单.json` 就行，三种类型：

| 类型 | 用途 | 例子 |
| --- | --- | --- |
| `rss` | 网站/博客/论坛提供订阅源 | 量子位、少数派、Solidot、大佬说 |
| `atom` | 盯 GitHub 开源项目的版本发布 | Claude Code、Ollama |
| `html_diff` | 没有 RSS，定期比对网页挑出新内容 | DeepSeek 更新日志、智谱新品页 |

改完下次运行自动生效；可以先跑 `python src/config_loader.py` 检查写得对不对。
详细的字段说明和现成模板见 [数据源配置说明.md](数据源配置说明.md)。

注意：`html_diff` 类型的源**第一次运行不会产出内容**（只是先存一份「底片」），
从第二次开始新出现的内容才算数——这是故意的，否则会把页面上的历史内容全当成新闻。

## 开启 AI 智能摘要（可选）

1. 到 [platform.deepseek.com](https://platform.deepseek.com/) 注册并充值（**5 块钱能用两三个月**）；
2. 在 API Keys 页面创建一个 Key（`sk-` 开头）；
3. 项目根目录新建文件 `.env`，里面只写一行：

   ```
   DEEPSEEK_API_KEY=sk-你的Key粘贴在这里
   ```

4. 重新双击 `一键刷新.bat`，简报右上角显示「AI 智能摘要」即成功。

`.env` 已在 `.gitignore` 中排除，**不会被提交到仓库**。欠费或 Key 失效时会自动降级为规则模式。

## 让 GitHub 每天自动更新（免费）

本机网络不一定能访问所有站点（比如 LinuxDo、V2EX、GitHub），
而 GitHub 的服务器在国外，这些源它都能抓，所以推荐**云端定时抓取 + 本地一键刷新**配合使用。

1. 把本仓库 fork 或克隆到自己的 GitHub 账号；
2. 仓库 **Settings → Secrets and variables → Actions → New repository secret**，
   Name 填 `DEEPSEEK_API_KEY`，Secret 填你的 Key（不配也能跑，只是没 AI 摘要）；
3. 打开 **Actions** 页签 → 左侧「每日抓取」→ **Run workflow** 手动跑一次，变绿即成功；
4. 之后每天**北京时间 8:00 / 14:00 / 20:00** 自动跑，数据自动提交回仓库；
   修改抓取时间就编辑 `.github/workflows/每日抓取.yml` 里的 `cron`（注意是 UTC 时间）。

想用手机看：只有**公开仓库**能开。仓库 **Settings → Pages → Source** 选
`Deploy from a branch`，分支选 `main` / `/ (root)`，保存后得到
`https://你的用户名.github.io/ai-info/`。

> GitHub 规定：仓库 60 天无任何活动，定时任务会被自动暂停。
> 隔一两个月手动点一次 Run workflow 就能保活。

## 常见问题

**命令行中文乱码？** 程序内部已强制 UTF-8。如仍乱码，先执行 `chcp 65001` 再运行。

**某几个源一直失败？** 双击 `探测数据源.bat` 看原因。确实用不了的源，
在 `配置/数据源清单.json` 里把它的 `"启用"` 改成 `false` 即可。

**数据来源是哪些？** 量子位、少数派、Solidot、InfoQ、大佬说、HN、LinuxDo，
以及 DeepSeek / 智谱 / Kimi / 阿里百炼的官方更新页等，完整清单见 `配置/数据源清单.json`。

**花钱吗？** 不配 Key 全程免费。配了 DeepSeek 后按量计费，每天三次大约几分钱。
