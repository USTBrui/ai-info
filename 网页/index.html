    怎么用这个看板？

    数据从哪来？
    页面本身不带数据，数据由项目里的 Python 脚本抓取生成，放在同目录的 data 文件夹里。

    怎么更新？
    两种方式任选：① 回到项目根目录，双击 一键刷新.bat；② 等 GitHub Actions 每天定时自动跑（需要你先按《使用说明.md》配置好）。

    推荐配置顺序
    第一次用，建议先跑一次 探测数据源.bat，看看哪些源在你家网络下能抓通，抓不通的可以在 配置/数据源清单.json 里把「启用」改成 false，速度会快很多。

    快捷键
    / 聚焦搜索框　Esc 清空搜索　S 只看收藏

    数据存在哪？
    收藏、已读、主题这些只存在你自己的浏览器里，不会上传到任何地方。
